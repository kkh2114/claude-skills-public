# 프리셋: 트렌드 조사 (trend)

## 입력
| 항목 | 물어볼 말 | 예 |
|---|---|---|
| 주제 | 「어떤 분야의 흐름을 보고 싶나요?」 | AI 에이전트 브라우저 |
| 관점 | 「누구 입장에서 보나요? (만드는 쪽/쓰는 쪽/투자)」 | 쓰는 쪽 |
| 키워드 | 「떠오르는 키워드는요?」 | Aside, Comet, computer use |
| 관련 문서 | 「가진 자료가 있으면 주세요.」 | — |

## 검색 범위 추천
- 기간: **최근 1~3개월**(흐름의 현재), 비교용으로 6~12개월 전 소스를 일부(보충 몫).
- 주요 사이트: **스레드·X·유튜브**(초기 신호) + 뉴스·블로그.
- 게시일 분포가 중요 → 날짜 미확인 소스를 최소화.

## 커버리지 질의
- 「최근 <기간>에 새로 등장한 것·사라진 것」 · 「언급이 늘어난 키워드와 그 근거」 · 「상반된 시각」
- 「초기 사용자 반응·불만」 · 「다음에 올 것에 대한 소스들의 예측」
- 시기별 비교: `--source-ids`로 최근 소스 묶음과 이전 소스 묶음을 따로 질의해 대조

## 설계 인터뷰
독자 · 형식(브리핑/뉴스레터/보고서) · 톤 · 분량 · 신호 강도 표시 여부(강/약 신호).

## 목차 틀
한 줄 요약 → 주요 트렌드 3~5개(근거·사례·신호 강도) → 반대 신호 → 시사점·다음 관찰 포인트 → 참고 소스

## 출력 기본 추천
웹 페이지(공유) 또는 파워포인트 브리핑, 보조로 Studio 오디오 개요(brief).
