# 프리셋: AI 기술 교안 (courseware)

## 입력 (한 칸씩)
| 항목 | 물어볼 말 | 예 |
|---|---|---|
| 기술구현 목표 | 「교안으로 가르칠 기술구현 목표를 적어 주세요. 무엇을 어떤 방향으로 구현하는지까지요.」 | Claude Code 스킬로 사내 보고서 자동화 |
| 키워드 | 「꼭 다뤄야 할 키워드는요? 모르면 제가 목표에서 뽑을게요.」 | SKILL.md, MCP, 서브에이전트 |
| 관련 문서 | 「이미 가진 관련 문서(파일·링크)가 있으면 주세요. 가장 먼저 노트북에 넣어요.」 | 사내 가이드 PDF |

## 검색 범위 추천
- 기간: **최근 3개월**(AI 도구는 빨리 바뀜). 개념·기초 위주면 12개월.
- 주요 사이트: **유튜브·스레드** (실습 영상·현업 후기) + 공식 문서는 보충 몫으로.
- 수집 목표: 유료 40~60개 / 무료 30~40개.

## 커버리지 질의 (공통 6개에 더해)
- 「<목표>를 처음부터 끝까지 따라 하는 단계와 각 단계의 도구·명령」
- 「각 단계에서 자주 나는 오류와 해결」
- 「같은 목표를 이루는 대안 방법과 장단점」
- 「실습에 쓸 수 있는 예제·데이터·코드」

## 설계 인터뷰 (한 칸씩, 추천값 제시)
| 항목 | 물어볼 말 | 추천/선택지 |
|---|---|---|
| 교안 목표 | 「수업이 끝나면 수강자가 무엇을 할 수 있어야 하나요?」 | 목표에서 뽑은 문장 제안 |
| 수강자 수준 | 「수강자는 누구예요?」 | 비개발자 입문 / 현업 실무자 / 개발자 |
| 톤앤매너 | 「말투는요?」 | 친근한 해요체 / 강의식 합니다체 / 간결한 개조식 |
| 서술 방식 | 「어떻게 풀어 갈까요?」 | 실습 따라하기 / 개념→예시→실습 / 문제 해결 사례 중심 |
| 분량·형식 | 「몇 차시, 차시당 몇 분이에요?」 | 3차시×90분 |

## 목차 틀 (차시별)
학습목표 → 왜 필요한가(사례) → 핵심 개념 → 따라하기 실습 → 자주 막히는 곳 → 정리·퀴즈 → 참고 소스

## 출력 기본 추천
강의용 파워포인트 + 배포용 워드, 보조로 Studio 퀴즈·오디오 개요.
