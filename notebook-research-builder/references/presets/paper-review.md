# 프리셋: 논문 리뷰 (paper-review)

## 입력
| 항목 | 물어볼 말 | 예 |
|---|---|---|
| 연구 질문 | 「어떤 질문에 답하려는 리뷰인가요?」 | LLM 에이전트의 도구 사용 평가 방법 |
| 범위 | 「포함/제외 기준은요? (분야·방법·언어)」 | 영어, 실험 논문만 |
| 핵심 논문·키워드 | 「꼭 넣을 논문이나 키워드는요?」 | SWE-bench, tool use |
| 관련 문서 | 「가진 PDF를 주세요 — 파일로 바로 넣어요.」 | 논문 PDF 5편 |

## 검색 범위 추천
- 기간: **최근 2~3년**(분야 따라 조정). 고전 논문은 기간 밖이어도 보충 몫으로.
- 주요 사이트: **arXiv·ACL Anthology·OpenReview·Semantic Scholar**. 해설은 유튜브·블로그(보충).
- 가능하면 PDF를 `--file`로 넣는다(본문 전체가 소스가 됨). 게시일 = 제출일/출판일.

## 커버리지 질의
- 「논문별 문제·방법·데이터·결과를 표로」 · 「방법론 계열 분류」 · 「결과가 서로 충돌하는 곳」
- 「공통 한계와 미해결 문제」 · 「평가 지표·벤치마크 비교」 · 「인용이 많은 기반 연구」

## 설계 인터뷰
독자(연구자/실무자/학생) · 형식(서베이/관련연구 절/발표) · 서술(연대기/방법론별/질문별) · 분량 · 인용 스타일.

## 목차 틀
연구 질문·범위 → 방법(검색·선정 기준) → 분류 체계 → 계열별 리뷰 → 비교표 → 한계·향후 과제 → 참고문헌

## 출력 기본 추천
워드(논문형) + 발표 파워포인트, 보조로 Studio 마인드맵·데이터 테이블.
